# Us App: Telegram Mini App для пары

Общее пространство для двоих (Алексей и его девушка): места и свидания, дом (покупки/дела/рецепты),
вишлист с секретными подарками, записки-сюрпризы, вопрос дня. Аналог Ottership, но проще, красивее и логичнее.
Язык интерфейса: русский. Пользователей всегда двое (одна «пара»).

## Стек
- `web/`: React 18 + TypeScript + Vite, чистый CSS (токены из `design-reference/intimate_ios_serenity/DESIGN.md`), lucide-react, шрифт Inter.
- `server/`: Node 22, Fastify 5, SQLite (better-sqlite3), ES-модули. Раздаёт и API, и собранный `web/dist`.
- Авторизация: подпись Telegram `initData` (HMAC) в заголовке `x-init-data`. Паролей нет.
- Бот: webhook `POST /api/tg/webhook/:secret`, пуши партнёру через `sendMessage`.
- Хостинг: VPS Hoster.by (Ubuntu 24.04, 1 CPU/1 GB), `https://usapp.kosalexus.by`. **На сервере живёт ещё `crm.kosalexus.by`: не ломать.**

## Команды
```
npm run install:all     # зависимости server + web
npm run dev:server      # API на :3100 с DEV_MODE=1 (вход по ?dev=111:Имя)
npm run dev:web         # Vite на :5173, проксирует /api на :3100
npm run build           # сборка фронтенда в web/dist
npm test                # тесты (проверка подписи Telegram)
```
Локально в браузере: `http://localhost:5173/?dev=111:Алексей` и во втором окне `?dev=222:Маша`.
Деплой: `deploy/SETUP.md`, обновление: `deploy/deploy.sh`.

## Структура
- `server/src/db.js` схема SQLite · `auth.js` валидация initData · `routes.js` весь API · `bot.js` Telegram · `questions.js` вопросы дня
- `web/src/pages/{Today,Together,Home,Memory}.tsx` четыре вкладки · `components/QuickAdd.tsx` центральная «+» · `pages/Onboarding.tsx` приглашение пары
- `design-reference/` макеты Stitch (`_1`…`_4`: Сегодня, Дом, Вместе, Память) и `DESIGN.md`. Оттуда берём цвета, радиусы, типографику.

## Дизайн-правила
Светлый минимализм в стиле Apple. Один акцент: коралловый `#FF6B5E`, только для главных действий и активной вкладки. Карточки белые, радиус 20px, мягкие тени, матовая нижняя панель, нижний отступ под home indicator. Без маскотов и геймификации. Не добавлять новые цвета и шрифты без причины.

## Ключевые решения (не менять без обсуждения)
- Пара = ровно 2 человека. Присоединение по коду `invite_<code>` (ссылка `t.me/<bot>?startapp=invite_<code>`).
- Подарки секретны: владелец вишлиста никогда не видит, что его подарок «взяли» (см. `GET /api/wishes`).
- Ответ на «вопрос дня» открывается обоим, когда ответили оба.
- Записки можно закрыть до времени `open_at`: текст партнёру не отдаётся, пока время не пришло (проверка на сервере).
- Синхронизация: опрос раз в 3–6 секунд пока приложение видимо (без WebSocket, для двух людей этого достаточно).
- Часовой пояс дня: Europe/Minsk (`TZ_OFFSET_HOURS=3`).
- Токен бота и секреты только в `server/.env` (в git не попадает). `DEV_MODE` запрещён в production.

## Сделано (v1)

быстрое «+» с автоопределением раздела · пуши партнёру о важном.

## Правила работы
- Перед правкой UI смотреть макеты в `design-reference/`. Проверять в виде 390×844.
- Любое изменение API сопровождать правкой типов в `web/src/types.ts`.
- После изменений: `npm test` и `npm run build` должны проходить.
